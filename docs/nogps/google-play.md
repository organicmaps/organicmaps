# Публикация NoGPS Maps в Google Play

Пошаговая инструкция и готовые ответы для Play Console. Тексты страницы магазина лежат в
`android/app/src/fdroid/play/listings/{uk,ru-RU,en-US}` (вариант `google` берёт их оттуда), политика
конфиденциальности — в [`privacy-policy.md`](privacy-policy.md).

## 1. Аккаунт разработчика

1. https://play.google.com/console — зарегистрироваться как **личный** аккаунт (или организация, если
   будет ФОП/ТОВ с номером D-U-N-S). Разовый взнос $25, проверка документа и телефона.
2. Контактная почта для пользователей: `most05062014@gmail.com`, сайт: `https://github.com/Ramzess-II/NoGPSMaps`.

## 2. Закрытое тестирование — обязательно для нового личного аккаунта

Новый личный аккаунт не может сразу выпустить приложение для всех. Google требует сначала закрытый тест:

- **12 тестировщиков** (на момент написания; Google меняет условия, Play Console покажет точное число на
  странице «Доступ к рабочей версии»), которые **приняли приглашение и не выходили из теста 14 дней
  подряд**. Считаются дни, когда тестировщиков было не меньше 12 одновременно, — если кто-то выйдет и
  останется 11, отсчёт начнётся заново.
- Тестировщики — это просто аккаунты Google. Вы добавляете их почты в список (или Google-группу) в
  Play Console → «Тестирование» → «Закрытое тестирование». Каждый получает ссылку, нажимает
  «Стать тестировщиком» и ставит приложение из Google Play как обычно. Приложение у них обновляется
  само при каждой новой версии.
- Пользоваться приложением каждый день не обязательно, но Google смотрит, что тест был настоящим:
  в заявке на доступ к рабочей версии спросят, как проходило тестирование, что нашли и что исправили.
  Отзывы тестировщиков приходят в Play Console приватно.
- После 14 дней — кнопка «Подать заявку на доступ к рабочей версии», ответы на вопросы о тесте и
  приложении, проверка обычно до 7 дней. После этого можно выпускать на всех (или открытым тестом).

**Где взять 12 человек:** друзья и семья с Android, знакомые водители — им же приложение и нужно.
Тестировщики не обязательно в Украине, но страны распространения закрытого теста должны включать их
страны.

Закрытый тест полезен и сам по себе: это и есть первые пользователи. И он не нарушает условие Organic
Maps о пределе ~1000 пользователей.

## 3. Ключ подписи

Google хранит **ключ приложения** (Play App Signing), а вы — только **ключ загрузки**, которым
подписываете файл для загрузки. Если ключ загрузки потеряется, его можно заменить через поддержку
Google; ключ приложения потерять нельзя, поэтому его и отдают Google.

1. Создать ключ загрузки (один раз). В терминале, в папке, где будет храниться ключ — **не в репозитории**:

   ```bash
   "C:/Program Files/Android/Android Studio/jbr/bin/keytool" -genkeypair -v -keystore nogps-upload.jks -alias upload -keyalg RSA -keysize 4096 -validity 10000
   ```

   keytool спросит пароль и имя. Пароль придумать надёжный и сохранить в менеджере паролей.
   **Сделать резервную копию** `nogps-upload.jks` (например, на флешку и в облако).

2. Создать файл `android/app/secure.properties` (он в `.gitignore`, в репозиторий не попадает):

   ```groovy
   ext {
     spropStoreFile = 'C:/путь/к/nogps-upload.jks'
     spropStorePassword = 'пароль'
     spropKeyAlias = 'upload'
     spropKeyPassword = 'пароль'
   }
   ```

3. В Play Console при создании первого выпуска согласиться на **Play App Signing** (по умолчанию).

## 4. Сборка

```bash
cd android
./gradlew :app:bundleGoogleRelease
```

Готовый файл: `android/app/build/outputs/bundle/googleRelease/NoGPSMaps-<код>-google-release.aab`.
Номер версии (`versionCode`) берётся из даты и номера коммита, каждая новая сборка — больше предыдущей.

Модуль `wear` (приложение Organic Maps для часов Wear OS) **не загружать**: он остался от Organic Maps.

## 5. Страница в магазине

| Поле | Где взять |
|---|---|
| Название, краткое и полное описание | `listings/<язык>/title.txt`, `short-description.txt`, `full-description.txt` |
| Значок 512×512 | `listings/en-US/graphics/icon/1.png` |
| Баннер 1024×500 | `listings/en-US/graphics/feature-graphic/1.png` |
| Скриншоты телефона (2–8 шт.) | `listings/uk/graphics/phone-screenshots/` (украинский интерфейс, центр Днепра) |
| Что нового | `release-notes/<язык>/default.txt` |
| Категория | Приложения → **Карты и навигация** |
| Политика конфиденциальности | ссылка на `docs/nogps/privacy-policy.md` на GitHub |

Язык по умолчанию — украинский (`uk`), переводы — русский (`ru-RU`) и английский (`en-US`).

**Не использовать** «Organic Maps» в названии, значке и скриншотах — это нарушение правил о выдаче себя
за другое приложение. Упоминание «На основе Organic Maps» в полном описании нужно по условиям Organic Maps.
Избегать слов «РЭБ», «военный», «глушение»: описание «навигация, когда GPS недоступен или неточен».

## 6. Анкеты Play Console

### Содержание приложения → Политика конфиденциальности
Ссылка: `https://github.com/Ramzess-II/NoGPSMaps/blob/main/docs/nogps/privacy-policy.md`

### Реклама
Нет рекламы.

### Доступ к приложению
Всё доступно без входа. Для проверки инерциальной навигации нужен адаптер ELM327 или блок ESP32 —
написать проверяющим, что без них работают карта, маршруты и ручной режим (нажать кнопку с пальцем и коснуться дороги, когда нет GPS).

### Возрастной рейтинг (анкета IARC)
Категория «Справочные, новостные или образовательные» / «Утилиты». На все вопросы о насилии, сексе,
азартных играх, наркотиках — нет. Взаимодействие пользователей — нет. Обмен местоположением с другими
пользователями — **нет** (местоположение не передаётся; «Поделиться» делает сам пользователь через
другие приложения). Ожидаемый рейтинг — 3+ / PEGI 3.

### Целевая аудитория
18 и старше (приложение для водителей). Не для детей.

### Безопасность данных (Data safety)
- Собирает ли приложение или передаёт ли данные пользователей? — **Нет.**
  Основание: местоположение и данные датчиков обрабатываются только на устройстве; разработчик не
  получает данных. Отчёт об ошибке отправляет сам пользователь из своего почтового приложения —
  Google не считает такую отправку сбором данных приложением.
- Шифруются ли данные при передаче? — Да (загрузка карт по HTTPS).
- Может ли пользователь запросить удаление? — Данных у разработчика нет; на устройстве удаляются
  удалением приложения.

Если Google не согласится с «Нет» (например, из-за журнала в отчёте об ошибке), указать:
«Местоположение — точное: собирается, не передаётся третьим лицам, необязательно, цель — исправление
ошибок и работа приложения».

### Фоновые службы (Foreground service types)

| Тип | Служба | Объяснение для Google |
|---|---|---|
| `location` | Навигация (`NavigationService`), запись трека (`TrackRecordingService`) | Пошаговая навигация и запись трека, запущенные пользователем, продолжают работать с выключенным экраном; пользователь видит уведомление и может остановить их. |
| `mediaPlayback` | Навигация | Голосовые подсказки поворотов во время навигации. |
| `dataSync` | Загрузка карт (`DownloaderService`) | Загрузка офлайн-карт, выбранных пользователем, продолжается в фоне с уведомлением о ходе. |

Для `location` Google попросит **видео** (до 1 мин, ссылка YouTube «доступ по ссылке»): построить маршрут,
нажать «Поехали», выключить экран — видно уведомление навигации и голосовую подсказку; включить экран —
навигация продолжается.

Разрешение `ACCESS_BACKGROUND_LOCATION` приложение **не запрашивает** — отдельная декларация не нужна.

### Новостные приложения, госприложения, финансы, здоровье
Нет / не относится.

## 7. Что проверить перед первым выпуском

- [ ] Релизная сборка (`googleRelease`) запускается: карта, загрузка карт, маршрут, навигация с голосом,
      ручной режим, ELM327, блок ESP32, экран «О приложении».
- [x] Скриншоты сняты заново с новым значком.
- [x] «Поделиться» отправляет ссылку openstreetmap.org: в браузере у всех, в приложении у его пользователей.
- [x] Редактирование OpenStreetMap выключено (флаг `MAP_EDITING`): для него нужно своё приложение OAuth.
- [ ] Пределы Organic Maps: не больше ~1000 пользователей без новой договорённости
      (счётчик — Play Console → Статистика).
